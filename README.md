# MĀRKA 🌱
### Every Journey Leaves a Mark.

MĀRKA is a carbon footprint tracking application that automatically estimates the carbon impact of a user's journey.

The application detects the user's starting location using device geolocation, allows the user to select a destination, calculates the distance travelled, and estimates the corresponding carbon footprint.

## ✨ Features

- 📍 Automatic starting-location detection
- 🗺️ Destination selection
- 🚗 Journey tracking
- 📏 Automatic distance calculation
- 🌱 Carbon footprint estimation
- 📊 Dashboard for viewing journey and carbon data
- 📈 Analytics and reports
- 🎯 Sustainability goals and challenges

## 🔄 How It Works

1. Start a journey.
2. MĀRKA detects the current location.
3. Select or search for the destination.
4. The application tracks the journey.
5. Distance travelled is calculated automatically.
6. Carbon footprint is estimated based on the journey.
7. The result is displayed on the dashboard.

## 🛠️ Technology Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** SQLite
- **Location:** Browser Geolocation API
